# fortress-password-manager-
Fortress — Secure Password & Notes Manager

A password and notes manager built with React and JavaScript. Data is encrypted on the client side, so sensitive information is never stored on the device in plain text.

Features
Client-side encryption: notes and credentials are encrypted before they are stored
Master-password authentication: one master password unlocks the vault
Auto-lock: the vault locks itself to protect your data
Category-based organization: keep notes and credentials sorted by category
Tech Stack
React
JavaScript
Client-side encrypted storage
Getting Started
Prerequisites
Node.js (v18 or later recommended)
npm
Installation
bash
git clone https://github.com/vikrambhadouriya44-art/Fortress.git
cd Fortress
npm install
Run locally
bash
npm start        # or: npm run dev  (check package.json "scripts")

Then open the URL shown in the terminal (usually http://localhost:3000 or http://localhost:5173).
